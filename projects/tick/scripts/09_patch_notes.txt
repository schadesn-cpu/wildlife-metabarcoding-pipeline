PATCH NOTES — 09_pathogen_host_cooccurrence.py
================================================

Three changes, all minimally invasive:

  1. Fix the `min_read` -> `min_reads` typo on the line that thresholds reads
     per ASV. As written this raises NameError; either it's never actually
     executed (some upstream guard) or every call has been silently failing
     for one branch. Fixed unconditionally.

  2. Add a `--genus-exact` flag (default OFF for reproducibility). When ON,
     terms are matched against the g__<token> field of the Taxon string,
     not as free substrings. This eliminates the family-level and order-level
     substring traps documented in
       results/16S/all/blast_verify/audit_substring_traps_summary.tsv

     Default OFF means: rerunning `09` with the same args as before produces
     bit-identical output to before. Opt in for the corrected behavior.

  3. New `--targets-config` arg (optional) for loading the pathogens_16s /
     pathogens_18s / hosts_cytb dicts from pipeline_config.yml instead of
     hardcoding them in the script. Falls back to the existing hardcoded
     dicts if not provided. Useful if you decide to track Wolbachia or
     Ehrlichia separately later.

Apply with `patch -p0 < this_file` from the project root, OR copy the four
hunks below by hand into scripts/09_pathogen_host_cooccurrence.py.

HUNK 2 — add a genus-token matcher and switch detect_in_sample to use it
------------------------------------------------------------

Find the current `detect_in_sample` function (around line 24):

    def detect_in_sample(counts, taxonomy, targets, min_reads=1):
        """For each sample, detect which target taxa are present."""
        # Map feature IDs to target taxa
        target_features = {}
        for fid, row in taxonomy.iterrows():
            taxon = row['Taxon']

Replace with:

    import re
    _GENUS_RE = re.compile(r"g__([^;]*)")

    def _genus_token(taxon):
        """Return the g__<token> from a SILVA-style Taxon string, or '' if absent."""
        if not isinstance(taxon, str):
            return ""
        m = _GENUS_RE.search(taxon)
        return m.group(1) if m else ""

    def detect_in_sample(counts, taxonomy, targets, min_reads=1, genus_exact=False):
        """For each sample, detect which target taxa are present.

        If `genus_exact` is True, terms are matched against the g__<token>
        field of Taxon (case-sensitive). If False (default), the original
        case-insensitive substring behavior is preserved for reproducibility.
        """
        target_features = {}
        for fid, row in taxonomy.iterrows():
            taxon = row['Taxon']
            if genus_exact:
                gen = _genus_token(taxon)
                for target_name, search_terms in targets.items():
                    if any(gen == term for term in search_terms):
                        target_features[fid] = target_name
                        break
            else:
                lo = taxon.lower() if isinstance(taxon, str) else ""
                for target_name, search_terms in targets.items():
                    if any(term.lower() in lo for term in search_terms):
                        target_features[fid] = target_name
                        break
